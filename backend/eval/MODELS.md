# Model comparison — receipt extraction

The same shipped pipeline (`extraction.extract_receipt` + the deterministic `receipt_fields.compute` logic + the shipped review gate) run across models over the hand-labelled set of **20** real Portuguese receipts. Generated by `backend/scripts/eval_models.py`.

- **Run date:** 2026-10-21
- **Honest caveat:** n=20 is a small set, so differences of a few points are **not statistically significant** — read this as a direction, not a leaderboard. Latency/cost are per-receipt estimates (summed across every orientation read).
